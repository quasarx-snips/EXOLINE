# Resource balance

EXOLINE defines 14 resources. Geological/material distribution in this Phase 1 pack uses seven natural channels: Metals, Water, Rare Minerals, Organics, Silicates, Volatiles, Nuclear Fuel. Food, Oxygen, Fuel, Components, Science Data, Reward Tokens and Blueprint Tokens are treated as derived/abstract gameplay resources.

Each body's seven natural percentages sum to 100%. The profiles are game-balance coefficients, not scientific composition measurements.
